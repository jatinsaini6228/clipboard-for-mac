## 2. Key Subsystems

### 2.1 Low-Overhead Pasteboard Polling (`PasteboardMonitor.swift`)
Instead of heavy global event taps, the app utilizes `NSPasteboard.general.changeCount`:
* Polling interval: 350ms via `Timer.scheduledTimer` added to `RunLoop.main` in `.common` mode.
* The kernel increments `changeCount` only when a process calls `declareTypes` or writes data to the pasteboard.
* Reading an integer costs less than 0.001ms CPU time per cycle.

### 2.2 Security & Credential Drop (`SensitiveDataFilter.swift`)
Before writing any clip to storage, `PasteboardMonitor` runs:
```swift
if SensitiveDataFilter.shouldIgnore(pasteboard: pasteboard, sourceBundleId: sourceBundleId) {
    return
}
```
* Checks for:
  - `org.nspasteboard.ConcealedType`
  - `org.nspasteboard.AutoGeneratedType`
  - `org.nspasteboard.TransientType`
  - `com.agilebits.onepassword`
  - Blacklisted bundle IDs (`com.apple.keychainaccess`, `com.bitwarden.desktop`, `org.keepassxc.keepassxc`)
  - Private key token markers (`-----BEGIN PRIVATE KEY-----`)

### 2.3 Direct Paste Keystroke Synthesis (`PasteService.swift`)
When a user selects a clip to paste:
1. `previousFrontmostApp` is recorded right before the HUD window is presented.
2. Selected clip is written to `NSPasteboard.general`.
3. HUD orders out and target application is activated:
   ```swift
   targetApp.activate(options: [.activateIgnoringOtherApps])
   ```
4. After 150ms delay, `CGEvent` posts `Cmd + V` (`virtualKey: 0x09`) directly to the system event tap.

### 2.4 Floating Acrylic NSPanel (`FloatingHUDWindowController.swift`)
* StyleMask: `[.borderless, .nonactivatingPanel, .fullSizeContentView]`.
* Level: `.floating` with collection behavior `[.canJoinAllSpaces, .fullScreenAuxiliary]`.
* Local keyboard monitor intercepts `Return`, `Esc`, `↑`, `↓`, `Cmd+C`, `Cmd+P`, and `Cmd+Backspace` without requiring Accessibility permissions for key capture.

## 3. Building & Testing

### Build Release App Bundle
```bash
./scripts/build_app.sh
```

### Run Automated Tests
```bash
swift run ClipboardTestRunner
```

### Run Development Executable via CLI
```bash
swift run Clipboard
```
